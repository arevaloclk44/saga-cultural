# SAGA Espacio Cultural

Sitio web de SAGA, espacio cultural en el piso 3 del Centro Comercial Paseo El Hatillo.

## Estructura

- `index.html` — página única (hero, misión, exposiciones, talleres y conversatorios, contacto)
- `images/` — logo e imágenes del espacio

Sitio estático, sin build ni dependencias. Para verlo en local, abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático.
